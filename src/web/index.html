How to Use the Platform

This platform allows facility managers to import monthly reports from partner DHIS2 instances into the central destination DHIS2 database. Follow these steps to execute a successful migration:

  1. Configure Connections: Go to the Settings tab and verify that the Destination DHIS2 credentials and Partner/Report Pivot Table links are correctly defined.
  2. Extract Data: Open the Import Data tab. Choose the Source Partner, the specific Report, the Year, and the Month. Click Extract Data to fetch raw records.
  3. Validate Mappings: Click Validate Mappings to translate element codes using global Excel rules. If there are unmapped UIDs, the system will allow you to download the updated Excel file, fill in the blanks, and upload it in the Manage Mappings tab.
  4. Simulation (Dry Run): Click Simulate Import (Dry Run) to test writing records to the target server without making permanent changes. This is highly recommended to identify conflicts.
  5. Commit Import: Mark the confirmation check and click Import to Destination to write the final values permanently.

General Information

This utility performs the Extract-Transform-Load (ETL) process of monthly facility reports between partner DHIS2 instances and the central destination instance.

Security Tip: Connection credentials for each server are stored locally and securely in the .env environment file.

Tips for Excel Editing

The global Excel file contains the following sheets representing mapping tables:

  • data_elements: Mapping of Data Elements (column 1: Source UID; column 2: Destination UID; column 3: Name).
  • organisation_units: Mapping of Organisation Units (column 1: Source UID; column 2: Destination UID; column 3: Name; column 4: Province; column 5: Country).

[⚠️] Warning: Do not change the sheet names or column positions to prevent loader parsing errors.
